# ThreatRoad Labs — Public

This is the public Threat Road lab repository. It includes **Lab 1** as a free sample:

- [LAB01 — Linux Fundamentals for Hackers](LAB01.md)
- [Lab 1 setup script](downloads/lab01-setup.sh)
- [Lab 1 cleanup script](downloads/lab01-cleanup.sh)

For full access to all Threat Road labs, visit [threatroad.com](https://threatroad.com/).

## Safety

Run the lab only in an isolated Ubuntu or Kali virtual machine. Do not run the setup script on your everyday computer, a work device, a production server, or any system containing personal data. Read the safety notice and prerequisites in [LAB01.md](LAB01.md) before starting.

## Start Lab 1

From the repository root, inside the isolated VM:

```bash
sudo bash downloads/lab01-setup.sh
```

When you are finished:

```bash
sudo bash downloads/lab01-cleanup.sh
```
